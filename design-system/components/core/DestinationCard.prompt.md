Full-bleed destination card. Image fills the card under a bottom gradient, location name in Playfair bottom-left, grey region pill top-right (the gold region tag is reserved for the destination detail hero — cards repeat in grids, and repeated gold defeats the one-gold rule). Hover scales the image to 1.02.

```jsx
<DestinationCard image="hunza.jpg" name="Hunza Valley" region="Gilgit-Baltistan" height={360} />
```

Let photography dominate — these are never bordered like editorial cards.
