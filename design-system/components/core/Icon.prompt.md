Lucide-style line icons, the brand's icon set. Grey (`var(--ttn-grey)`) for UI, gold for accents.

```jsx
<Icon name="mapPin" size={16} color="var(--ttn-gold)" />
<Icon name="arrowRight" size={16} />
```

Sizes: 16 inline, 20 standalone UI, 24 feature. Available: mapPin, mountain, camera, users, star, arrowRight, menu, x, chevronDown, externalLink, phone, mail, check, facebook, clock.
