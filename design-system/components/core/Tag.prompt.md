Tags, region labels and the TTN Certified badge.

```jsx
<Tag variant="category">Trekking</Tag>
<Tag variant="region">Gilgit-Baltistan</Tag>
<Tag variant="certified">TTN Certified</Tag>
```

Variants: `category` (neutral slate pill, grey text), `region` (gold fill, black uppercase), `certified` (black bg, gold border + text, uppercase), `gold` (bare gold uppercase label used above card titles). Keep one gold element per section: `region` and `gold` are single-use — a hero or one featured card — never repeated across a grid; grids use `category`.
